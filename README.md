# proyecto-ciberseguridad
Proyecto final de Ciberseguridad (Tecmilenio) · Organización ficticia: Stark Manufactura.

- [`parte-a-app-web/`](parte-a-app-web/): Parte A, aplicación web de laboratorio (SQL Injection, XSS, IDOR/BOLA).
  - Tag `v1-vulnerable`: versión vulnerable. Tag `v2-segura`: versión corregida (rama `fix/vulnerabilidades`).
- [`parte-b-infraestructura/`](parte-b-infraestructura/): Parte B, mejora de infraestructura: MFA (TOTP) en el SSH del servidor para el perfil privilegiado, refuerzo de firewall (ufw/nftables), evidencias reales (Mac + VM Ubuntu en UTM + teléfono con Aegis) y procedimiento de respuesta a incidentes.
